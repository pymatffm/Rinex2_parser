# RINEX 2 Parser

The current `main.py` parses RINEX 2 observation files and prints a summary; it
does not run the legacy navigation/VTEC processing pipeline.

Run it on the included sample:

```sh
python3 main.py
```

Or specify a RINEX 2 observation file:

```sh
python3 main.py Data/kepa3150.13o
```

With `uv`, you don’t need to activate the environment to run a command—use uv run, for example:

```shell
uv run python3 main.py Data/kepa3150.13o
```

The parser API also returns a pandas DataFrame with one row per epoch/satellite.
Its index is `(epoch, satellite)` and its MultiIndex columns contain each
observation type's `value`, `lli`, and `signal_strength` fields:

```python
from pathlib import Path
from main import read_observation_dataframe

header, observations = read_observation_dataframe(Path("Data_2/kepa3150.13o"))
print(observations.loc[(slice(None), "R21"), ("L1", "value")])
```

Export the table to CSV from the command line:

```sh
python3 main.py Data/kepa3150.13o --csv observations.csv
```

Parser tests:

```sh
python3 -m unittest discover -s tests -v
```


# RINEX 3/4 Parser and GNSS Data Extraction

Pure-Python parser for RINEX 3.x and 4.00 observation and navigation files
(GPS, Galileo, BeiDou first-class; GLONASS/QZSS/NavIC/SBAS parsed generically),
with time-scale conversion (GPST / UTC / TAI / BDT / GST), tidy pandas
extraction, summary statistics and plots.

Requires: Python >= 3.9, numpy, pandas, matplotlib (pytest for the tests).

## CLI

    python rinex_tool.py obs <file.o> [-o outdir] [--systems GEC]
    python rinex_tool.py nav <file.n> [-o outdir] [--systems GEC]

`--systems` accepts one or more RINEX system letters (default: `GEC`):

| Letter | GNSS |
|---|---|
| `G` | GPS |
| `E` | Galileo |
| `C` | BeiDou |
| `R` | GLONASS |
| `J` | QZSS |
| `I` | NavIC (IRNSS) |
| `S` | SBAS |

For example, `--systems GREC` selects GPS, GLONASS, Galileo, and BeiDou.

`obs` writes `observations_long.csv` (tidy: one row per satellite/epoch/signal,
with time in the file scale plus GPST/UTC/TAI), `phase_pseudorange.csv`,
`observations_wide.csv` (one row per sat/epoch, one column per code),
`snr_stats.csv`, `visibility.csv`, `summary.json`, and four plots
(SNR vs time, SNR distribution, satellite count, per-satellite timeline).
`nav` writes `ephemeris.csv` (Keplerian + clock parameters, TOC in the file's
time scale and GPST), plus `sto.csv` / `ion.csv` for RINEX 4 system-time
offset and ionosphere records.

With `uv`, you don’t need to activate the environment to run a command—use uv run, for example:

```shell
uv run python rinex_3_4_tool.py obs Data_3_4/sample_v304.24o -o Data_3_4/ --systems E
```

## API

    from rinex_tool import read_obs, read_nav, to_gpst, convert_time, gps_week_tow

    header, df = read_obs("SITE001.24o")      # df: tidy DataFrame
    header.approx_xyz                        # antenna XYZ from the header
    header.approx_llh                         # derived geodetic position
    header.obs_types                          # {"G": ["C1C", ...], ...}
    to_gpst(t, "BDT"); convert_time(t, "UTC", "TAI")
    nav = read_nav("SITE001.24n"); nav.ephemeris

## Time scales

GPST–UTC = TAI–UTC − 19 s using the full leap-second table (1980–today);
GPST = GST, BDT = GPST − 14 s. UTC conversions are correct across leap
seconds (1972+). `gps_week_tow` returns continuous GPS week (no 1024 rollover)
and time-of-week.

## Tests

    python -m pytest tests

Test fixtures are synthetic RINEX files generated by `tests/make_sample.py`
(simulated GPS+Galileo+BeiDou observables, 114 sats, cycle slips, LLI/SSI
flags); `example_out/` holds pre-generated samples and full CLI output.
